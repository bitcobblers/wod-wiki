Write it in Markdown

NoteEditor · canvas:home

Blank page + typeahead

Notes are freeform Markdown. A fenced block tagged ```time runs as a workout timer; ```log records without running; ```log:climbing scopes the climbing dialect. In-note analytics use ```query — there is no ```wql fence.

Every line collects metrics: reps (10 Kettlebell Swings), resistance (24kg · 185lb), timed rest (*:30 Rest — the star makes it required), rounds ((3) · (3 Rounds) · (5 Sets)). In the app the editor autocompletes fence names, frontmatter properties, and tags — movement names are not autocompleted.

One line, many facts

(3)
  10 Kettlebell Swings 24kg
  *:30 Rest

Efforts × measures compound into queryable facts — sum:totalVolume{'{}'} by {'{effort}'} reads exactly what a line like this records. The metrics beat below shows all three panes.

👉 Handoff: the Run pill sits on the fence in the editor above — press it and this exact script becomes the clock in the next beat.

Simulation limits (deliberate)

Standalone HTML facsimile — no React components are mounted; each surface is a faithful structural reproduction with an in-memory demo executor. The executor parses only the explicit supported sample shapes (round-based ```time fences; WQL aggregates over totalVolume / totalReps / tis / sessionLoad / totalDistance / calc.adherence with key:value filters, one or two dims, last/from…to windows). Unsupported input is preserved and refused with a readable message — never silently rewritten. No journal save, no cast device, no persistence; example data is labeled at the point of use.

Design verdict

Ship Variant A — the continuous walkthrough keeps demo context visible at every beat and matches the existing scroll-caption story. B is the strongest power-user surface; its stage-context column is the pattern worth reusing. C is the most distinctive but the most layout-fragile; steal its margin annotations for the journal empty state. All three share one state machine and identical component facsimiles, so the choice is purely presentational.
