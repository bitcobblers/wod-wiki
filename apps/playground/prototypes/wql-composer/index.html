WQL Composer Redesign Prototypes

Three clickable, responsive explorations built to resolve the core issues from the UI critique: desktop and mobile parity, unified command palette versus view dropdown behavior, and unambiguous scope visualization across every part of a WQL query. Each concept lets you switch between Desktop (1440), Tablet (768), and Mobile (390), test all four routes (/journal, /efforts, /notes, /dashboards), and trigger ⌘K / Ctrl+/ live.

Desktop, Tablet & Mobile Parity

Eliminates the 640px vs 1024px split, enforces 44px mobile targets, adds +Filter everywhere, and pins Cancel/Apply in a 3-region scroll-safe sheet.

Command Palette vs View Dropdown

Keeps view headers calm via anchored popovers, gives mobile streams a dedicated Filter Sheet with no dead result taps, and isolates plain Find from WQL.

Intuitive Scope & Part Navigation

Separates Aggregate vs Metric AST spans, highlights active pills from raw WQL carets without focus theft, flags ignored filters, and returns Esc focus to the pill.

Concept A: Anchored Split-Pill Rail

Tightens the existing StreamQueryBar paradigm into labeled split-pills (no orphaned × icons) with a floating anchored popover directly beneath the active token and an optional collapsible WQL strip.

  • Header stays 54px at all times; popover floats with directional caret
  • Caret movement in raw WQL passively lights the matching pill
  • Minimal disruption to current WqlComposer React state
Open Concept A

Concept B: Zoned Grammar Track

Visualizes WQL anatomy as four explicit zones (WHAT, WHERE, WHEN, GROUP) linked to an interactive syntax line above it so even implicit slots and split heads (sum vs totalVolume) are obvious.

  • Explicit empty/implicit slots (e.g. Any time) are directly clickable
  • Live syntax token ↔ zone slot visual coupling on click or caret move
  • Best clarity for multi-clause /dashboards aggregate queries
Open Concept B

Concept C: Focus-Lens Spine

Strips cognitive load down to one natural-language sentence bar at rest, opening a single-focus notched spine where the edited pill merges cleanly into its option canvas — identical on desktop, mobile, and ⌘K.

  • Lowest visual noise at rest (sentence-style clickable phrases)
  • Notched active tab eliminates repeating values 4–6×
  • 100% shared interaction topology across views, mobile, and ⌘K
Open Concept C
