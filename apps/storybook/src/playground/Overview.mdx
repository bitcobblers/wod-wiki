# Playground Overview — Content Types, Views & Navigation

Every record in the WOD.wiki Playground is projected through a unified **`Entry`** model (`apps/playground/app/lib/entryMapper.ts`). How an entry looks—its icon, semantic color badge, metadata chips, inline preview, and action buttons—is determined by its **`EntryKind`** and **`sourceNotebook`**.

      <td><code>LibraryRow</code> + <code>StickyGroupHeader</code></td>

## 4. 4-Zone Shell & Menu Architecture

Navigation across the Playground is divided into four coordinated zones sharing a single `MenuSpec` contract (`apps/playground/app/nav/menuModel.ts`):

1. **Zone 1 — Primary Icon Rail (`AppRail`)**: Fixed 56px left rail holding L1 destinations (Home, Notebooks/Library, Dashboards, Pages, Search `⌘/`, Settings).
2. **Zone 2 — Context Sidebar (`NavSidebar` / `ConditionsNavPanel`)**: Route-scoped L2 panel listing saved WQL shortcuts, notebook trees, and recent stream hits.
3. **Zone 3 — Page Header & Mobile Thumb Dock (`PageActions` & `ResponsiveActions`)**: Desktop header action bar (`NewEntryCombo`, `SyncActivityIndicators`, `CastButtonRpc`, `ActionsMenu` `⋯`) that automatically collapses into a thumb-zone FAB + overflow sheet on mobile (`<1024px`).
4. **Zone 4 — Secondary "On This Page" Rail (`SecondaryNav` / `StreamControlsNav`)**: Right-hand L3 rail on wide screens (`2xl+`) and `⋯` menu on smaller screens, housing Date Window, Group-By checkboxes, the 5-mode Layout switcher, Field visibility toggles, and the in-page section outline (`MenuList`).
