# Seed & Database Plane (`parameters: { database: true }`)

Storybook runs two distinct data planes so component tests stay fast while workbench tools exercise the real Playground storage stack:

1. **In-Memory Isolation (Default)**: Stories mount without IndexedDB or network sync. They use deterministic in-memory fixtures (`JOURNALS`, `entryFixtures`, `note-editor`, or `MockContentProvider`).
2. **Opt-In Seed & IndexedDB Plane (`parameters: { database: true }`)**: Stories that test persistence, live feed syncing, or multi-database switching opt into `DatabaseProvider` via Storybook parameters.

---

## 1. How the Opt-In Decorator Works

In `apps/storybook/.storybook/preview.tsx`, the global decorator inspects `context.parameters?.database`:

```tsx
// apps/storybook/.storybook/preview.tsx
(Story, context) => {
  if (context.parameters?.database) {
    return (
      <DatabaseProvider>
        <Story />
      </DatabaseProvider>
    );
  }
  return <Story />;
}
```

When `parameters: { database: true }` is set on a story's `meta` (or individual story):

1. `DatabaseProvider` (`apps/storybook/src/database/DatabaseContext.tsx`) waits for `whenStorageReady()` on the active IndexedDB database (default: `wodwiki-db`).
2. It runs `runBootFeedSync()` once per database to import the compiled core seed artifact (`/seed/core/manifest.json` + NDJSON chunks emitted by `scripts/sync-seed.ts` into `apps/storybook/public/seed`).
3. It exposes `useDatabase()` so the story can read `activeName`, `databases`, `feed`, `feedSources`, `selectDatabase()`, `createDatabase()`, and `importFeedSource()`.

---

## 2. Opting In from a Story

```tsx
import type { Meta, StoryObj } from '@storybook/react-vite';
import { useDatabase } from '../database/DatabaseContext';

const meta: Meta = {
  title: 'Workbench/My Seeded Tool',
  parameters: {
    layout: 'padded',
    database: true, // Mounts DatabaseProvider + syncs /seed/core into IndexedDB
  },
};
export default meta;
```
