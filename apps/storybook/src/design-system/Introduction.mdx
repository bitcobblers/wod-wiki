## Testing & Verification Model

1. **Fast In-Memory Isolation by Default**: Component stories mount with synchronous in-memory fixtures (`parameters.domainState`, `inMemoryEventStore`, or static `QueryExecutor`s) with zero IndexedDB overhead.
2. **Toolbar Property Overrides**: Use the Storybook toolbar to switch **Theme** (Mineral Light / Arctic Frost Dark on `<html>`), **Viewport** (Phone Portrait `375×812`, Phone Landscape, Tablet, Desktop, Wide 4-Zone Shell, Chromecast TV `1920×1080`), **Domain State** presets (stories without `parameters.domainState` display an explicit status pill), and **Motion** (`prefers-reduced-motion` simulation).
3. **Opt-In Database Plane**: Stories that specifically test browser IndexedDB persistence and feed syncing opt in via `parameters: { database: true }` (see <a href="?path=/docs/workbench-resources-seed-database--docs"><code>Workbench / Resources / Seed &amp; Database</code></a>).
4. **Interactive Controls (`args` + `react-docgen`)**: Use the **Controls** panel at the bottom of any component story to toggle states, props, workout scripts, and layouts dynamically.
5. **Accessibility (`@storybook/addon-a11y`)**: Every story is checked against WCAG 2.1 AA contrast and ARIA rules; Design System, Primitives, Dialogs, and Analytics Widget stories enforce `a11y: { test: 'error' }`.
6. **Automated Interaction (`play()`)**: Key organisms, dialogs, widgets, and molecules carry `play()` functions executed in headless Chromium via `bun run test:storybook`.
