## 🧪 Testing & Verification Model

1. **Fast In-Memory Isolation by Default**: Component stories mount with synchronous in-memory fixtures (`inMemoryEventStore`, `MockContentProvider`, or static `QueryExecutor`s) with zero IndexedDB overhead.
2. **Opt-In Database Plane**: Stories that specifically test browser IndexedDB persistence and feed syncing opt in via `parameters: { database: true }`.
3. **Interactive Controls (`args`)**: Use the **Controls** panel at the bottom of any component story to toggle states, props, workout scripts, and layouts dynamically.
4. **Accessibility (`@storybook/addon-a11y`)**: Every story is checked against WCAG 2.1 AA contrast and ARIA rules in the **Accessibility** addon tab.
5. **Automated Interaction (`play()`)**: Key organisms and molecules carry `play()` functions executed in headless Chromium via `bun run test:storybook`.
