# Whole Notes and sparse actionable blocks

## Contract

Clean cutover. Existing databases and seed artifacts are disposable. No data migrations, old-format readers, aliases, backfills or legacy query compatibility. This plan does not reset any database.

- Store authored Markdown once in `Note.rawContent`. An embedded `Note.blocks` map holds occurrence IDs, kinds, content versions and revision-bound, half-open UTF-16 ranges for workouts, queries, registered widgets and interactive embeds. Prose/headings/frontmatter stay source; presentation sections are transient. Unknown or invalid content stays recoverable.
- Delete persisted NoteSegments. Add an immutable `block_revisions` store keyed by `[noteId, blockId, version]`, with exact block source, kind, workout dialect/sport and saved timestamp. Append-only writes reject an existing key with different content. Keep `block_index` and `block_efforts` disposable and current-only; normalized SQL search text is a projection, not another writable source. Only actionable blocks receive revision rows, never prose paragraphs.
- Keep identity separate from location and fingerprint. Copies get new IDs; explicit moves retain IDs; duplicate blocks stay distinct. Map editor changes and persist the map across reopen. Ambiguous bulk replacements get fresh IDs, never guessed session associations.
- Append v1 when a block is first saved and one new revision per changed saved block, including intermediate versions never run. Moves/prose edits and identical saves add no revision. Reverting creates a new monotonically numbered revision, not an overwrite. Removing a block removes its live map/index entries but retains its revision history. History means saved states, not every keystroke.
- At run start, commit the current Note source/map, any changed block revisions and the Session pin `[noteId, blockId, blockVersion]` atomically. The runtime freezes that exact revision's source/dialect/sport; completion never resolves the latest block. Replay reads the immutable revision, so a separate duplicate Session source snapshot is unnecessary. Saved revisions remain available for history even when no Session references them. No old-history migration.
- `:note` searches titles and full bodies; `:block` returns actionable blocks only. Update current callers, no prose-block compatibility. Runtime-event WQL `:segment` is unrelated and stays unchanged.

Delete reconstruction, retirement sweeps and segment resolution. Reject stale source revisions rather than overwrite concurrent edits or reuse a version key. Regenerate core with `bun run generate:seed`, Community with updated `wod build` in `../wod-wiki-seed`, and recreate development databases.
