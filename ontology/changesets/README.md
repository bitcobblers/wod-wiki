# Ontology Changesets (`ontology/changesets/`)

Gated bidirectional changeset graphs (`<timestamp>-<slug>.trig` + `<timestamp>-<slug>.md` review summaries) generated by `bun run ontology:changeset`.

## Lifecycle

1. **Propose** (Code -> Ontology):
   ```bash
   bun run ontology:changeset propose [--base <ref>] [--staged] [--slug <slug>]
   ```
   Creates a `pending_approval` `.trig` changeset graph with `prov:` metadata and proposed `:domain`, `:code`, and `:bridge` triples, plus a `.md` human review summary.

2. **Review & Approve**:
   ```bash
   bun run ontology:changeset list
   bun run ontology:changeset approve <id>
   # or reject:
   bun run ontology:changeset reject <id> --reason "..."
   ```

3. **Apply & Align** (Ontology -> Code):
   ```bash
   bun run ontology:changeset apply <id>
   ```
   Refuses to apply unless `changeset:status` is `"approved"` (or `--approve` is explicitly passed). Merges approved triples into `ontology/bridge/changesets-applied.ttl`, marks the changeset `"applied"`, and triggers `sync-from-ontology`.
