Page Types — Chrome & WQL Crosswalk
Sources: apps/playground/app/lib/routes.ts · app/nav/appNavTree.ts · app/views/stream/streamProfile.ts · docs/app/on-this-page.md · page-composition-spec.md. Sparse data pass — verify against code before relying on it.

Shared chrome (all page types)

Every page type renders inside the same three chrome channels; per-type tables below only record what differs.

Sticky headerTop app bar (65px mobile / 104px desktop): L1 nav toggle, page title/crumb, Search (Ctrl+/), New split button (jumps to today / pick a date), cast. Trailing ⋯ Page options (hidden ≥1520px): mirrors the L3 rail — stream controls, secondary sections, On this page, Download Markdown (only when the route resolves a document).
L2 navLeft sidebar. L1 rail = Home, Journal, Notebooks, Notes, Playgrounds, Dashboard, Efforts, Equipment, Sessions, Settings + external Buy Me a Coffee. Stream zones mount the shared ConditionsNavPanel: create action, landing row, saved WQL shortcuts (save/clear), grouping presets (“Arrange by…”, “All time”), and the FacetProperties accordion — the only surface that renders where-clause filters.
L3 navRight rail ≥1520px; same content in ⋯ menu (984–1519px) and right drawer (<1024px). Exactly one writer per page kind publishes l3Items; empty writers skip. Scroll items jump to section ids; time fences get a Run secondary action.

Home & Guide (canvas)

Learning/marketing surface: markdown prose chapters with a live editor or runway demo panel. Home runs the plan→track→analyze tour; Guide is 8 consolidated chapters (start, protocols, structure, metrics, clock, wql, dashboards, sessions).

Routes/, /guide/*, /p/* (generic note-built pages)
Sticky headerShared bar; hero Run starts the current workout in the hero viewport; guide pages add the challenge-progress badge. From the first content section a sticky editor/runway panel pins beside the prose (mobile: sticky panel under the bar).
L2 navHome children: New journal entry + the 8 guide chapters (fixed guideOrder).
L3 navHome: markdown sections (level > 1) + Workout N per ```time/```log fence (Run affordance). Guide: sections only — workout fences skipped.
Key buttonsRun, Try it, Reset, Stop/Exit (records partial results), Scroll panel / Scroll page toggle.

Journal

Plan/track home. The stream lists notes by date; a date page owns its notes 1:N; running a workout records results against the note’s canonical pageId. /notes/:noteId is the canonical single-note editor for any note kind.

Routes/journal (stream), /journal/:date/ (date page), /notes/:noteId, /journal/:date/:uuid
Sticky headerShared bar; New split button jumps to a date page; date pages also carry New note.
L2 navJournal zone: create New journal entry, landing All entries. Predefined extra link: All → /journal?q=:note{!source:playground}.
L3 navStream: dynamic date groups (date-group-YYYY-MM-DD); top-10 dates placeholder pre-load. Note pages: headings + time blocks (Run) + log blocks. Date page: none today (documented gap).
Default WQL:journal{} last 4w — target note, scope favorites [journal]
Key buttonsRun (per time block), Edit pencil, Clone (copy to another date/page, links back), Note relationships, Download Markdown, stream controls (date window + Group By) in the L3 rail.

Notebooks

Notebook directory listing (`notebook/{slug}`): predefined defaults (notebook/journal, notebook/playground, notebook/guides), user-created notebooks, and seed-delivered notebooks tied to their source URL.

Routes/catalogs
L2 navNotebooks zone: landing All notebooks; same ConditionsNavPanel chrome.
L3 navStream date/tag groups.
Default WQL:notebook{} by {tag} (alias :catalog{} by {tag}) — target note, scope favorites [feeds]; seedNotice on
Key buttonsNew Notebook (opens CreateNotebookDialog), Manage Notebooks (opens CatalogsManagerDrawer), Sync notice CTA.

Notes & Notebook Landing

Notebook workout streams and curated notebook landing pages (README + live WQL queries). Only user-created notes (seedOrigin !== 'seed') are editable; seed-delivered notes open read-only and can be cloned into any user-writable notebook.

Routes/feeds, /c/:slug, /c/:slug/:date, /feeds/:feedSlug, /feeds/:feedSlug/:date/:item, /collections/:slug(/:workout) (legacy aliases redirect)
L2 navNotes zone: create New note (source mode), landing All notes. Predefined extra link: Notebook crosswalk → /catalogs.
L3 nav/c/:slug: sections + Explore + one link per notebook workout (opens editor). Note item: note index (headings + time/log blocks).
Default WQL/feeds → :feed{} — target note, scope favorites [feeds]; seedNotice on. /c/:slug → :note{notebook:<slug>} by {date} — cards layout, session level.
Key buttonsNew note, Clone to notebook/journal, Launch on clock, Execute query, member-note navigation.

Playgrounds

Scratch pages for experiments and quick-run workout drafts; each playground is an independent note with its own page.

Routes/playgrounds (list), /playground/:id
L2 navPlaygrounds zone: create New playground → /playground, landing All playgrounds.
L3 navNote page index (headings + time blocks with Run + log blocks); stream: date groups.
Default WQL:playground{} by {date} last 1w — target note, scope favorites [playground], sessions shelf visible
Key buttonsNew playground, Reset, Run (quick-run any fenced ```time block).

Efforts

Movement catalog: MET multipliers, discipline tags, intensity tiers. Effort detail edits structured frontmatter through the metadata overlay and projects into the efforts registry.

Routes/efforts, /effort/:slug, /e/:slug (?mode=, ?tab= controls)
L2 navEfforts zone: create New effort → /e/new?mode=create, landing All Efforts.
L3 navStream groups by discipline (group-discipline-<slug>). Effort detail: note index + results-by-version badges.
Default WQL:effort — target effort, no scope favorites; “No efforts match your search.” empty state
Key buttonsNew effort, structured metadata edit (frontmatter overlay), edit pencil, Run, mode/tab switch.

Sessions

Recorded executions: round splits, completed reps, elapsed duration; result detail drills to segment-level statements.

Routes/sessions, /session/:date, /results/:sessionId
L2 navSessions zone: landing All Sessions; no create action.
L3 navStream date groups; detail pages: none today (gap).
Default WQL/sessions → :session{} last 1d — target session, result level. /session/:date → :session{} from <date> to <date>. /results/:id → :session{result:<id>, plane:segment} — segment level.
Key buttonsStream controls only (date window + Group By); surfaces are read-only analysis.

Dashboards

Composed chart pages (timeseries, bar, toplist, summary cards) powered by embedded WQL; /dashboards doubles as the WQL explorer workbench.

Routes/dashboards (list + explorer), /dashboard/:slug, /d/:slug
L2 navDynamic DashboardsNavPanel: Explorer + vault-created dashboards + prebuilts + New dashboard action (runtime data, not static children).
L3 navNone today (documented gap) — candidates: widget/chart section anchors.
Default WQLExplorer landing query runs on load (deep-link ?q= wins; per-route override via Settings → Pages). Dashboard cards run their saved query fences.
Key buttonsRun (executes latest draft), Save (choose destination), Edit query, temporary filters, toggle edit for query fences, View Settings (Edit query / card-arrangement fallback).

Settings

Browser-local preferences: appearance/audio, profile, per-surface WQL defaults, tag-type CRUD, storage & sync. Nothing here touches the active page query unless saved.

Routes/settings → appearance; /settings/{profile,appearance,queries,tags,sync,storage,system} (data/database legacy aliases redirect)
L2 navStatic children: Profile, Appearance, Pages, Tags, Sync, Storage, System.
L3 navIntentionally none.
Default WQLPages section edits per-route defaultWql / scope favorites / Group-By options (routeWqlConfig, localStorage; empty = system default).
Key buttonsPer-section saves (browser-local), Reset to system default, tag CRUD, sync/storage actions.
